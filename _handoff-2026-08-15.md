## Non-negotiable rules (Momo's, in force everywhere)
1. **One engine.** Every surface gets its number from `allowance.compute()` (three lenses:
   計畫/水位/軌跡; 水位 sets the line, others only tighten, only when positive).
   `budget.status()` is now a thin wrapper over it. "They all need to agree, even if
   approximate."
2. **Missing data never reads as good news.** Lenses abstain with no observations; unknown
   day counts are "unknown" not zero; provisional dates are provisional. "Say she doesn't
   know."
3. **Expected income NEVER raises today's allowance** — it only shortens how long the pile
   must stretch (`periods_to_money`). allowance.py:~295 comment is the spec.
4. **Tools then speak.** agent.py runs tools first; receipts are generated by tools, never
   the model. Every write is a Change row (undoable). Undo now has conflict detection
   (refuses non-LIFO when later changes touched the same data).
5. **Her answers are sacred.** status `enriched`/`reconciled` rows and taught merchant
   memories survive every re-sweep. Boot no longer mutates: the eleven seed passes live in
   `main.run_maintenance()` behind the 重掃歷史 button on 訓練輪 (POST /api/maintenance).
6. **Assisted judgement voice.** Situation + both levers priced + no verdict. No guilt
   (a slow month is usually a booking failure, not a spending one). Keep bluntness and
   auntie nosiness. Traditional Chinese, Taiwanese wording ONLY — never simplified or
   mainland phrasing. Momo converses in English; the product speaks 台灣繁中.
